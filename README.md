# Hybrid Identity Architecture & Governance Engineering Portfolio

A hands-on engineering repository containing deployments, configuration files, and automated workflows across Identity Governance & Administration (IGA), Privileged Access Management (PAM), and security telemetry.


| Domain | Platform | Core Focus |
| :--- | :--- | :--- |
| **Identity Governance** | SailPoint IdentityIQ & ISC | BeanShell Rules, XML Workflows, JSON Transforms, Schema Mapping |
| **Privileged Access** | CyberArk PAM | EPV/PrivateArk Vault, Safe Management, Privileged Access Reviews |
| **Access Management** | Microsoft Entra ID & Okta | Conditional Access, PIM JIT Elevation, SAML/SCIM Federation |
| **Security Analytics** | Multi-Vendor SIEM | Cross-Platform Telemetry, Identity Threat Hunting Queries |

## Portfolio Contents

### [01. Custom Rule Engineering & BeanShell Scripts](./01-IIQ-Rules-BeanShell)
* **Objective:** Custom Java-based BeanShell rules to handle object behavior, data parsing, and target account correlation.
* **Key Skills:** BuildMap Rules, Correlation Rules, Custom Map Rules, SailPoint API, BeanShell Scripting.

### [02. Lifecycle Manager (LCM) & Business Workflows](./02-IIQ-LCM-Workflows)
* **Objective:** Configuration files and XML business processes designed to automate Joiner-Mover-Leaver (JML) lifecycle events.
* **Key Skills:** Workflow XML, Step Configuration, Provisioning Engine, Workitems, Lifecycle Manager (LCM).

### [03. Application Onboarding & Direct Connectors](./03-IIQ-Application-Onboarding)
* **Objective:** Configuration steps for onboarding authoritative sources and target systems using out-of-the-box and custom connectors.
* **Key Skills:** Schema Mapping, Active Directory Direct Connector, JDBC/Delimited File Connectors, Rule-Based Account Correlation.

### [04. CyberArk PAM Configurations & Cross-Pillar Integration](./04-CyberArk-PAM-Integration)
* **Objective:** Deployment of core CyberArk components and integration setups linking privileged vault lifecycles to SailPoint IGA governance.
* **Key Skills:** Enterprise Password Vault (EPV), CPM, PVWA, Safe Management, Privileged Access Reviews, SCIM and REST Integration.

### [05. Entra ID Zero Trust & Access Control](./05-Entra-Conditional-Access)
* **Objective:** Deployment of context-aware Conditional Access policies and Privileged Identity Management (PIM) to enforce least privilege.
* **Key Skills:** Entra ID, Just-in-Time (JIT) access, MFA enforcement, Zero Trust Architecture.

### [06. Okta Workforce Identity & SAML Federation](./06-Okta-SAML-Provisioning)
* **Objective:** Setting up single sign-on (SSO) federation, group rules, and inbound/outbound SCIM user provisioning.
* **Key Skills:** Okta Administration, SAML 2.0, SCIM Protocol, Lifecycle Management (LCM), Salesforce Integration.

### [07. SIEM Engineering & Advanced Threat Hunting](./07-SIEM-Threat-Hunting)
* **Objective:** Custom detection logic and behavioral queries written to monitor identity-based attacks within enterprise SIEM platforms.
* **Key Skills:** Splunk (SPL), Microsoft Sentinel (KQL), IBM QRadar (AQL), Log Analysis, Identity Security Monitoring.

### [08. Identity Attribute Transforms & API Automation Engine](./08-Identity-Transforms-API-Automation)
* **Objective:** Creating cloud identity profile mappings and string transformations using the SailPoint REST API and Postman.
* **Key Skills:** JSON Transforms, Postman Orchestration, SailPoint SaaS v3/Beta APIs, VS Code Integrations, OAuth 2.0.

### [09. Advanced Access Governance, Forms Engine & App Porting](./09-Advanced-Governance-Forms)
* **Objective:** Building interactive data-validation intake forms and moving configurations across environments using the Configuration Hub engine.
* **Key Skills:** Forms Engine JSON, Configuration Hub Export/Import, Role Discovery, Tenant Environment Porting.
